# tr 相关 6 个易混音 一次性分清

## 1. /tr/ 清辅音（最常用）

**读音：戳**

单词：tree tree [triː] 树

口诀：**短促轻戳**

## 2. /dr/ 浊辅音

**读音：桌**

单词：dry [draɪ] 干的

口诀：**震动出声 桌**

## 3. /tʃ/

**读音：吃**

单词：chair 椅子

## 4. /dʒ/

**读音：知**

单词：job 工作

## 5. /ts/

**读音：次**

单词：cats 猫 (复数)

## 6. /dz/

**读音：子**

单词：beds 床 (复数)

---

# 最简区分口诀（超好记）

1. **tr = 戳** 轻
2. **dr = 桌** 重
3. **tʃ= 吃** 长
4. **dʒ= 知** 浊
5. **ts = 次** 快
6. **dz = 子** 沉

# 短句秒练

tr tree 戳树
