# Roblox 项目读取工作流

如果你是新对话里的 Codex，请先读取：

```text
WORKFLOW_MANIFEST.json
00_START_HERE_给Codex.md
```

工作流文件夹名可以是任意名称。不要根据文件夹名判断；请根据 `WORKFLOW_MANIFEST.json` 和 `00_START_HERE_给Codex.md` 判断。

本文件夹的用途：

```text
让 Codex 在接手一个新的 Roblox 项目时，先自动创建分析目录、空 md 和 Studio 导出工具；
然后指导用户在 Roblox Studio 里运行导出脚本；
最后读取 Audit_*.md，把项目结构、脚本、Remote、素材、动画音效和关键源码整理成可接手资料。
```

不要从功能开发开始。先完成项目读取。
