# Roblox Rojo 新项目初始化操作手册

## 这两个文件怎么用

以后新开 Roblox 项目时，把这两个文件交给 Codex：

```text
SKILL.md
使用手册.md
```

然后直接发送这段指令：

```text
请读取我提供的 SKILL.md 和 使用手册.md。
按里面的 Roblox Rojo 新项目初始化流程，在当前工作目录创建一个新项目。

项目名：<填写项目名>
目标：学习用 / 原型用 / 正式项目起步

要求：
1. 不要使用任何旧电脑的固定路径。
2. 如果缺少工具，先告诉我缺什么、怎么安装。
3. 生成带中文注释的 Luau 代码。
4. 生成 VS Code 推荐插件、settings、tasks。
5. 配置 Immersive Translate，但 API key 只标注填写位置，不写入仓库文件。
6. 初始化后运行 rojo sourcemap 和 stylua 检查；如果工具缺失，明确说明。
7. 最后解释每个目录和第一条客户端-服务端闭环。
```

## 用户只需要做什么

你只需要提供三件事：

```text
项目名
项目放哪里
项目用途：学习 / 原型 / 正式起步
```

如果你懒得选路径，就直接说：

```text
在当前工作目录创建。
```

## Codex 应该先检查什么

Codex 不应该一上来就写文件。它应先检查当前环境：

```text
Roblox Studio 是否已安装
VS Code 是否已安装
Git 是否可用
Rojo CLI 是否可用
StyLua 是否可用
当前目录是否适合创建项目
目标项目文件夹是否已存在
```

Windows 下常用检查命令：

```powershell
git --version
rojo --version
stylua --version
code --version
```

Roblox Studio 和 Rojo Studio Plugin 有时需要人工在 Studio 内确认，Codex 应说明清楚。

## Codex 创建项目时的标准结果

新项目应生成这样的结构：

```text
MyGame/
  default.project.json
  README.md
  .gitignore
  wally.toml
  stylua.toml
  .vscode/
    extensions.json
    settings.json
    tasks.json
    immersive-translate-api-key.md
  src/
    ReplicatedStorage/
      Shared/
        GameConfig.luau
        RemoteNames.luau
        InstanceUtil.luau
    ServerScriptService/
      Main.server.luau
      Services/
        DataService.luau
        RewardService.luau
    StarterPlayer/
      StarterPlayerScripts/
        Main.client.luau
        ClientModules/
          UIController.luau
          RewardController.luau
```

## 第一版必须实现的闭环

第一版不要做复杂游戏系统，只做一个完整、能解释的最小闭环：

```text
玩家看到 UI 按钮
-> 点击领取奖励
-> 客户端 LocalScript 捕获点击
-> 客户端通过 RemoteEvent 发起请求
-> 服务端 Script 接收请求
-> 服务端 Service 校验冷却和资格
-> DataService 修改本局数据
-> 服务端把结果返回客户端
-> 客户端更新 UI 文本
```

核心原则：

```text
客户端只能请求。
服务端负责裁决。
奖励数值、冷却、数据修改都由服务端决定。
```

## .luau 文件规则

Codex 必须按这个规则生成文件：

```text
Main.server.luau
-> Roblox Script
-> 放在 ServerScriptService
-> 服务端运行

Main.client.luau
-> Roblox LocalScript
-> 放在 StarterPlayerScripts
-> 每个玩家客户端运行

普通 .luau
-> Roblox ModuleScript
-> 只有被 require() 时才运行
```

不要把所有逻辑都写进一个文件。起步阶段至少分成：

```text
入口脚本
共享配置
Remote 名称
服务端数据模块
服务端奖励模块
客户端 UI 模块
客户端奖励模块
```

## default.project.json 标准映射

`default.project.json` 应把本地文件映射到 Roblox Studio：

```text
src/ReplicatedStorage/Shared
-> ReplicatedStorage/Shared

src/ServerScriptService
-> ServerScriptService

src/StarterPlayer/StarterPlayerScripts
-> StarterPlayer/StarterPlayerScripts
```

起步项目里 `ReplicatedStorage/Packages` 可以先建成空 Folder。等真正使用 Wally 包时，再处理真实 `Packages/` 映射。

## VS Code 插件要求

`.vscode/extensions.json` 应推荐：

```text
evaera.vscode-rojo
JohnnyMorganz.luau-lsp
JohnnyMorganz.stylua
tamasfe.even-better-toml
ms-vscode.PowerShell
liujie2288.immersive-translate-vscode
```

用途：

```text
Rojo 插件：辅助 Rojo 工作流
Luau LSP：Luau 语法、补全、诊断
StyLua：格式化 Luau
TOML：编辑 wally.toml
PowerShell：Windows 脚本支持
Immersive Translate：翻译代码注释和 Markdown，不改原文件
```

## Immersive Translate 配置

`.vscode/settings.json` 可以生成默认配置：

```json
{
  "immersiveTranslate.service": "deepl",
  "immersiveTranslate.defaultSourceLanguage": "auto",
  "immersiveTranslate.defaultTargetLanguage": "zh-CN",
  "immersiveTranslate.textColor": "#888888",
  "immersiveTranslate.cache.enabled": true,
  "immersiveTranslate.advanced.chunkSize": 50
}
```

API key 不要写进项目文件。

必须生成 `.vscode/immersive-translate-api-key.md`，内容说明：

```text
Ctrl+Shift+P
-> Immersive Translate: Set API Key
-> choose translation service
-> paste API key there
```

## VS Code Tasks

`.vscode/tasks.json` 至少包含：

```text
Rojo: serve
Rojo: sourcemap
StyLua: check src
```

对应命令：

```powershell
rojo serve default.project.json --address 127.0.0.1 --port 34872
rojo sourcemap default.project.json --output sourcemap.json
stylua --check src
```

说明：

```text
rojo serve 是本机临时同步服务。
电脑重启、终端关闭、VS Code 关闭后，需要重新启动。
它不是发布游戏，也不是 Roblox Studio 永久在线服务。
```

## 验收标准

Codex 完成后必须给出这些结果：

```text
创建了哪些文件
Rojo sourcemap 是否通过
StyLua check 是否通过
VS Code 插件配置是否生成
Immersive Translate API key 填写位置在哪里
如何启动 rojo serve
如何在 Roblox Studio 连接 Rojo
第一条客户端-服务端闭环怎么跑
```

如果检查失败，不能含糊说“应该可以”。必须写清楚：

```text
失败命令
失败原因
要用户做什么
Codex 能继续做什么
```

## 禁止事项

新项目初始化阶段不要做这些：

```text
不要接真实 Robux 商品
不要改 DataStore schema
不要接 UGC / Skin / Aura
不要把客户端当可信来源
不要把 API key 写进仓库
不要默认使用旧电脑路径
不要一次性引入大型框架
不要跳过 Roblox Studio 连接步骤解释
```

## 如果只有这两个文件，没有脚本

如果新环境里只有 `SKILL.md` 和本手册，没有 `scripts/New-RobloxRojoProject.ps1`，Codex 应该：

```text
1. 按 SKILL.md 和本手册先重建脚本或直接生成项目文件。
2. 保持同样的目录结构。
3. 保持同样的 VS Code 配置。
4. 保持同样的客户端-服务端最小闭环。
5. 所有 Luau 文件必须带中文注释。
6. 生成后执行相同验收流程。
```

不要因为缺少旧路径而停止。路径由当前工作目录和用户指定目录决定。

```text

请按这套 Roblox Rojo 新项目工作流，在当前目录创建新项目。
项目名：MyGame

```
